FramePort（影像港口）是一款面向个人摄影用户的 macOS 应用，用来处理拍摄结束后的素材整理。接上存储卡，选择要导入的日期和保存位置，预览文件名，再复制并校验。需要多留一份原件时，可以同时选择备份位置。

如果文件已经在电脑里，也可以只用“独立压缩”：拖入照片或视频，生成更小的副本，方便之后传到手机上查看。原件保留，压缩后的文件另存。

媒体处理在本机完成。我们希望把日常拷卡和压缩做得顺手，让个人用户少花些时间整理文件。当前版本不包含 AI 分析、手机连接或照片库云同步。

## 从存储卡导入

FramePort 可以读取 Mac 上已挂载的存储卡、磁盘和已有文件夹。相机或录音设备的文件需要先通过读卡器、磁盘挂载等方式让 Mac 能够访问；当前不支持 PTP / MTP 直连。

一次导入的流程是：

1. 选择来源，扫描其中的照片、视频和录音。
2. 按日期选择需要的素材，设置保存位置；如果需要第二份原件，再添加备份位置。
3. 核对原文件名、导入后的文件名和保存路径。
4. 确认导入。复制后进行 SHA-256 校验，分别显示导入与备份的结果。

日期以文件中能读到的信息为依据；缺少拍摄日期时，可能回退到文件名或其他时间信息，导入前请核对预览。

SHA-256 校验用于核对复制前后的文件内容是否一致。默认归档会把原件集中放在相册的 `Originals` 文件夹，文件名加上序号和日期，文件内容保持不变。需要压缩副本时，可在导入设置里开启“生成轻量副本”，副本会单独保存。

这种整理方式适合日常个人拍摄，但不保证复制完整卡结构。依赖相机代理文件、专有容器或完整剪辑素材包的工作流，仍需另行保留完整的原卡备份。

## 只想压缩已有照片或视频

从工具栏打开“独立压缩”，拖入文件，选择保存位置，再开始处理。这里无需先创建相册或加入拷卡队列。

副本直接保存在你选择的文件夹，文件名带 `_light` 后缀；遇到重名会加编号，不覆盖已有文件。这个入口接收单独的照片和视频，不递归处理文件夹，也不压缩独立录音。

每完成一个文件，列表就会更新它的结果。取消后，已完成的副本会保留；当前批次中有失败或取消的项目，可以选择“继续未完成”。独立压缩的批次记录不会跨应用重启恢复。

### 画质和文件大小

压缩使用一套默认设置，无需选择码率或质量档位。照片输出 HEIC，最长边不超过 6000 像素，不放大小图；视频输出 MP4，通常使用 HEVC，最高保留 4K。已经足够小、编码兼容的视频，可能保留原有编码或只重新封装，避免重复压缩。

文件能缩小多少，取决于原始分辨率、编码和画面内容。文件体积的缩减比例不能直接换算成画质损失，这里也不承诺视觉无损。RAW 的渲染和媒体解码由 macOS 提供，能够原样导入某种格式，不代表当前系统一定能预览或压缩它。

### 拍摄时间和地点

副本会尽量保留原件中已有且可读取的拍摄时间、时区、GPS 地点，以及相机品牌和型号。原件没有的地点或时间信息不会通过猜测补齐，部分厂商私有字段也可能无法写入副本。

这些信息需要由接收文件的照片应用正确读取。目前已有部分 Mac“照片”样本通过验证，但 iPhone 导入和 iCloud 同步还未完成测试，带小数秒拍摄时间的视频仍可能出现时间偏移。导入后应查看照片信息页的日期和地图；“最近添加”按导入顺序排列，单凭这个列表不能判断拍摄时间是否丢失。

旧的压缩副本不会自动更新。需要使用本版的元数据处理时，请从原件重新生成副本，再检查照片应用中的结果。

## 下载与安装

| 项目 | 当前支持情况 |
| :--- | :--- |
| Mac | Apple Silicon（M 系列），暂不提供 Intel 版 |
| macOS | 声明最低版本为 macOS 15；目前在 macOS 27 上测试过，其他版本待验证 |
| 界面语言 | 简体中文、英文，跟随系统首选语言 |
| 当前版本 | 0.88 Public Beta 1；应用内显示 0.88 / Build 12；发布标签为 `v0.88.0-beta.1` |

1. 点击页面顶部的下载链接获取 ZIP。版本页面同时提供 SHA-256 校验信息。
2. 解压，将 `FramePort.app` 拖入“应用程序”，再打开。
3. 第一次使用时，先选几份已有备份的素材，完成一次导入或压缩，检查文件和拍摄信息。请保留原件。

> 当前安装包使用 ad-hoc 签名，尚未获得 Apple 公证，Gatekeeper 检查未通过。确认下载来源和文件完整性后，如决定继续，可在尝试打开后查看“系统设置 → 隐私与安全性”中针对 FramePort 的“仍要打开”入口。部分系统环境可能不提供该选项，具体操作见 [Apple 官方指南](https://support.apple.com/en-us/102445)。

## 这次公开测试还有哪些限制

这是公开测试版，尚非 1.0 稳定版。除了上面的安装和照片元数据限制，还有几项需要在试用前了解：

- 取消视频压缩时，偶尔会留下临时目录，原因仍在调查。
- 大批真实素材、长视频、设备断连及另一台 Mac 上的表现，还没有完成充分测试。
- 最新批次列表在实际窗口中的显示、键盘操作和 VoiceOver 仍需完整检查。

具体问题及建议见 [已知问题](docs/KNOWN_ISSUES.md)，测试覆盖范围见 [本版验证说明](docs/VERIFICATION.md)。
